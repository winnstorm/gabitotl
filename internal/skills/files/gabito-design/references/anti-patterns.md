# Generic-output tells (all media)

These patterns make work look automatically generated. Each module lists its own;
this file holds the cross-medium ones and the way to fix them. A tell is not
forbidden: it is a default, so use it only when you can say why it serves this goal.

## How to use this list

1. Scan the finished piece for the tells below.
2. For each one, decide: remove, replace, or justify in one sentence.
3. Do not swap one tell for the opposite tell; solve the underlying design problem.

## Content tells

- **Filler copy.** Headlines such as "Unlock the power of...", "Seamless
  experience", "Elevate your workflow", "Revolutionize". Fix: say the specific
  thing, with a number or a noun the reader recognizes.
- **Triplets everywhere.** Three features, three steps, three testimonials,
  always three. Fix: use the number the content actually has.
- **Lorem ipsum and "Feature 1".** Fix: write or request real content; mark
  placeholders loudly when real content is unavailable.
- **Invented proof.** Made-up statistics, testimonials, logos, awards. Fix: use
  real, sourced evidence or leave it out and say so.
- **Restating the title.** Intros that repeat the heading; conclusions that
  repeat the body. Fix: start with the point.
- **Vague buttons.** "Submit", "Click here", "Learn more" everywhere. Fix: the
  verb and the object ("Download the report").

## Visual tells

- **Sameness.** Every block the same size, radius, shadow and spacing. Fix: vary
  scale and rhythm so one thing leads.
- **Decoration standing in for design.** Gradients, glows, blobs, glass, shadows,
  emoji, and clip art used to fill space. Fix: use space, scale and alignment.
- **Default look.** Default font, default accent, default radius, default chart
  theme, default template. Fix: make at least type, color and spacing decisions
  on purpose, and record them.
- **Rainbow and neon.** Many saturated hues, or purple-blue gradients on dark.
  Fix: neutral base, one accent, semantic colors for status only.
- **Centered everything.** Centered paragraphs, centered lists, centered cards.
  Fix: left-align reading content; center only short single-focus items.
- **Border and card overload.** Boxes around everything, boxes inside boxes.
  Fix: group by space and a change of background; use one container level.
- **Icon confetti.** An icon beside every item, in mixed styles. Fix: icons only
  where they speed recognition, one consistent set.
- **Fake depth.** 3D charts, bevels, drop shadows on text. Fix: flat and precise.
- **Stock imagery.** Smiling teams, handshakes, abstract globes. Fix: real
  product views, specific photography, or no image.
- **Low-contrast "elegance".** Light gray text on white, tiny captions. Fix:
  meet contrast minimums; elegance comes from proportion, not from fading.
- **Uneven details.** Mixed corner radii, stroke weights, gaps that are almost
  equal. Fix: tokens, then an alignment pass.

## Process tells

- Building before deciding the goal, audience and hierarchy.
- Copying a trendy style without a reason tied to the subject.
- Piling on features of the tool (every chart type, every effect) because they exist.
- Never viewing the result. Fix: render, look, adjust.
- Declaring it "clean and modern" as a justification. Fix: name the decisions.

## The replacement test

For any element you want to remove or replace, ask: if the user's competitor used
this exact element unchanged, would anyone notice? If not, it is a default; make
a decision or delete it.
